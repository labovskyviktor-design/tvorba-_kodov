# Materiály a dokumentácia

Sem nahrajte PDF dokumenty s pravidlami a metodikou pre tvorbu kódov stavieb.

## Očakávané dokumenty

- Pravidlá číslovania stavebných objektov
- Metodika tvorby kódov profesií
- Štandardy názvoslovia podlaží a etáp
- Akékoľvek ďalšie PDF s pravidlami

## Poznámky

Tieto súbory sa **nenasadzujú** na Vercel – slúžia len ako referenčná dokumentácia
pre úpravu pravidiel v súbore `src/config/codeRules.js`.
